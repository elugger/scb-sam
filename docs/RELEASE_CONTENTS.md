# 本论文开源内容范围

范围仅为当前主表28行及H/HP/HQ/HPQ消融4组。统一脚本是用户入口，不代表所有模型与数据实现强行放进一个文件。

计划交付：
- 模型、损失、训练、推理、评价的可读源代码，主表各方法和消融分支的实际定义。
- 一个统一入口与逐实验冻结配置，实际数据划分/预处理规范、随机种子、预算和checkpoint选择规则。
- 环境依赖、硬件/显存需求、从数据准备到评价的具体命令。
- 必需上游预训练权重的精确来源/版本/SHA/本地位置；本项目监督前缀的生成方式及可选下载。
- 论文对应聚合结果、指标单位、选轮与已见开发结果后的筛选说明。
- 自有Apache-2.0、第三方许可与引用；医学数据提供合规获取说明，代码仓库不附患者影像。

三个cascade模块的可读源码已补齐并与训练字节码逐一验证；构建器是依据实际字节码恢复的源码，原文件未找到，详细身份见`CASCADE_SOURCE_RECOVERY.md`。现阶段仍需解决旧准备回执/输入身份/源码散列的跨机器绑定，以及完整新机训练验收。只整理权重和一层入口不能消除这些问题。结果报告工具或字节码等价核验的成功不等同于端到端训练复现成功。

本地整理时下载的权重已移出源码项目；不上传大权重到普通Git，不发布所有中间checkpoint，也不复活已取消删除的开发试验。

复现信息组织参考[NeurIPS Paper Checklist](https://neurips.cc/public/guides/PaperChecklist)，这不是对所有期刊施加同一强制清单。
